# 个人AI工作台 — Windows 本机网页版安装包

本方案安装的是“本机后台服务 + 浏览器页面”，不启动 Electron 窗口。领导双击桌面快捷方式后，服务会在后台静默启动并自动打开 `http://127.0.0.1:8787`。

## 构建安装包

在普通 Windows 终端执行：

```bash
npm install
npm run web:installer
```

构建脚本会依次完成前端生产构建、生产依赖裁剪、内置 Node 运行时复制和 NSIS 编译。它优先使用 `MAKENSIS_PATH`，其次查找 PATH 和 electron-builder 的本地 NSIS 缓存。

输出目录为 `release-web/`：

```text
个人AI工作台-Web版-Setup-0.2.0.exe
个人AI工作台-Web版-Setup-0.2.0.exe.sha256
更新说明-0.2.0.txt
```

安装包不包含仓库 `.env`、`.local`、SQLite、OAuth 令牌或任何真实密钥。

## 首次安装

1. 双击 Setup.exe。
2. 有 D 盘时默认目录为 `D:\个人AI工作台`，也可选择其他本机 NTFS 目录。
3. 安装器写入程序、内置 Node、隐藏启动器并创建桌面/开始菜单快捷方式。
4. IT 编辑安装目录下 `config\app.env`，填入 Outlook、钉钉和 AI 配置。
5. 双击桌面“个人AI工作台”，浏览器会自动打开。

目标目录必须是本机固定 NTFS 磁盘。不要安装到网络映射盘、U 盘或云同步目录。

## 开放平台回调

发布版固定使用 8787：

- Outlook：`http://127.0.0.1:8787/api/outlook/oauth/callback`
- 钉钉：`http://127.0.0.1:8787/oauth/dingtalk/callback`

需提前在 Azure Entra 和钉钉开放平台登记。开发环境原有 5174 回调可继续保留。

## 启动与日志

- “个人AI工作台”：静默启动服务并打开浏览器；重复点击不会创建多个服务。
- “停止工作台”：停止后台服务。
- “重启工作台”：用于修改配置或排障后重启。
- “导出本地备份”：停止服务、复制配置和数据、恢复服务并打开备份目录。
- 日志：`安装目录\logs\`。

关闭浏览器不会停止后台服务；自动同步会继续运行。

## 升级与回滚

直接运行新版 Setup.exe。安装器会读取首次安装目录，并自动执行：

1. 停止旧服务。
2. 备份 `config` 与 `data` 到 `backups\rollback`。
3. 安装新版本到 `versions\<新版本>`。
4. 切换候选版本并执行数据库迁移。
5. 调用 `/api/health` 验证启动。
6. 验证失败时恢复数据并切回上一版本。

升级不会覆盖 `config\app.env`。不要在升级时另选新目录；安装器检测到旧版本后会锁定原路径。

## 卸载

默认只删除程序、运行时和快捷方式，保留 `config`、`data`、`logs`、`backups`。卸载页可选择永久删除全部本地数据；该选项默认关闭，并有二次确认。

## 钉钉白名单

安装包不会改变公网出口。钉钉返回 IP 白名单错误后，相关数据源会暂停自动重试并继续展示上次缓存；IT 更新白名单后，在“系统/接入”页点击“更新白名单后重新同步”即可恢复。

## 发布限制

当前安装包未做代码签名，Windows 可能提示“未知发布者”。可核对随包提供的 SHA-256 文件后由 IT 放行。
